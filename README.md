# Video Language Helper

在 **YouTube 和 B站** 边看视频边练听力、口语的 Chrome 侧栏扩展。支持双字幕、逐句停顿、录音对比、听写与可选的有道发音评估。基础功能无需额外账号。

## 功能与用法

| 模块 | 功能与操作 |
| --- | --- |
| 字幕阅读 | 自动读取网站字幕，按自然语句展示；播放、切句或选择片段时，高亮内容靠上显示，与顶栏保留留白；手动滚动不被抢回。点击字幕即可定位。YouTube 支持人工与自动字幕；B站人工字幕优先，没有人工轨时使用 AI 字幕。 |
| 双语对照 | 顶部两个下拉框分别选择主字幕、第二字幕；选择“无第二字幕”关闭对照。可选语言以视频实际提供的字幕轨为准，不自动翻译。 |
| 播放控制 | 底栏播放/暂停共用一个按钮，也可按 `Space`：按一次暂停，再按一次继续连续播放。普通状态下，使用上一句、下一句或重播会播放该句并在句尾暂停。 |
| 逐句跟读 | 点击底栏“逐句跟读”或按 `E`：每句播完，停顿与该句字幕持续时间相同的时长，再自动播放下一句；最后一句停住。再次点击或按 `E` 关闭。 |
| 跟读录音 | 点击右下角麦克风或按 `F` 开关独立的“跟读模式”；片段播完暂停，按 `S` 重播。点击“录音”或按 `R` 开始/停止，停止后自动保存在浏览器，单次最长 2 分钟。回放行的三点菜单列出“录音 #1、#2…”；选择后按播放键或 `G` 试听，固定正常速度，可拖动进度和删除条目。 |
| 发音评估 | 录音后点击播放键右侧的星光按钮或按 `V`，用有道评估当前选中的录音。显示综合、准确度、流利度和完整度；点击单词查看音素及重音提示。成功评分随录音保存，再次点击或按 `V` 只查看，不重复调用；切换录音会切换评分。需配置自己的有道语音评测应用，按有道账户计费。 |
| 片段调整 | 在麦克风模式下，用片段旁的上下扩展/收缩按钮选择一句或多句，也可使用下方快捷键；调整后的片段最长 60 秒，播完后停住等待练习。 |
| 音高对比 | 在麦克风模式下展开“音高曲线”或按 `P`：青色是原声、橙色是当前选中的录音，曲线表示语调、底部阴影表示音量，空白处表示停顿。可开关曲线与音量层，悬停问号查看说明；原声采集失败仍可查看录音曲线，并单独重试原声。不是发音评分。 |
| 听写练习 | 在麦克风模式下点击书本按钮或按 `H`，字幕暂时隐藏；输入听到的内容，按 `Enter` 检查。显示正确率、漏写和多写，忽略大小写与标点；支持查看练习历史、最好及平均成绩。 |
| 视频倍速与设置 | 点击底栏倍速按钮选择视频 `0.5 / 1 / 1.5 / 2` 倍速，不改变录音回放速度。顶部“更多选项 → 设置”可切换系统/浅色/深色主题、设置优先字幕语言或恢复默认设置。 |

**逐句跟读和麦克风跟读是两个独立模式：** 前者只停顿、不录音；后者用于录音、音高和听写，不自动跳到下一句。进入一个模式会退出另一个；普通播放键或 `Space` 从暂停恢复时，回到连续播放。

例如，一句字幕持续 3 秒，逐句跟读就停顿 3 秒；改变播放倍速不会缩短这段停顿。音高对比首次采集原声时会自动播放所选片段，完成后恢复原播放位置。

## 安装与开始

需要 **Chrome 120+、Node.js 22+**。

1. 下载或克隆仓库，在项目根目录执行：

   ```sh
   npm ci
   npm run build
   ```

2. 打开 Chrome 扩展管理页 `chrome://extensions/`，开启“开发者模式”，选择“加载已解压的扩展程序”，指向项目的 `.output/chrome-mv3` 文件夹。
3. 打开 YouTube 或 B站视频，点击扩展图标打开侧栏，等待字幕加载后选择语言并开始练习。

**启用发音评估（可选）：** 在“更多选项 → 设置 → 发音评估 · 有道”填写应用 ID 与应用密钥并保存。有道应用须绑定「语音评测」，接入方式选 API；不能使用 DeepSeek Key。保存配置不调用评估，录音后点击 `V` 才发送所选录音及对应字幕。支持英语、中文，单条最长 120 秒；失败不自动重试，超时可能已产生用量。[有道接口说明](https://ai.youdao.com/DOCSIRMA/html/tts/api/yypc/index.html)

## 快捷键

字幕加载后，在视频页面或侧栏使用；输入框内不会抢占普通输入。点击侧栏顶部键盘图标可随时查看。

| 快捷键 | 操作 |
| --- | --- |
| `Space` | 暂停 / 继续连续播放；松键不再次切换 |
| `A` / `S` / `D` | 上一句 / 重播当前句或练习片段 / 下一句 |
| `E` | 开关逐句跟读 |
| `F` | 开关麦克风跟读；扩展连接时取代网站的 F 全屏快捷键 |
| `Shift + ,` / `Shift + .` | 减速 / 加速 |
| `?` | 显示快捷键帮助 |
| `R` / `G` / `Esc` | 麦克风模式：开始或停止录音 / 播放或暂停录音 / 取消录音 |
| `V` | 麦克风模式：评估当前录音 / 查看已保存评分 |
| `P` / `H` | 麦克风模式：开关音高曲线 / 听写 |
| `[` / `]` | 麦克风模式：向前 / 向后扩展片段 |
| `Shift + [` / `Shift + ]` | 麦克风模式：收缩片段开头 / 结尾 |
| `/` | 听写模式：聚焦输入框 |
| `Enter` / `Shift + Enter` | 听写输入框：检查答案 / 换行 |

## 使用提示

- **字幕不准或缺失：** 字幕质量取决于网站原轨，AI 字幕可能有误；本扩展不提供 OCR、语音转写或自动纠错。加载失败可点击重试，或“更多选项 → 重新获取字幕”；需要登录的视频请先登录对应网站。
- **听写时查看答案：** 悬停或聚焦“查看字幕”，可临时显示参考文本。
- **本地保存：** 录音、评分、听写记录和偏好保存在当前浏览器；只有主动评估时，所选录音及对应字幕会发送至有道。应用凭据仅保存在本机扩展配置，不同步、不回显，内容脚本无权读取；这不等同于系统级加密保险箱。卸载扩展或清除其数据会丢失记录；恢复默认设置不删除练习历史，“清除有道凭据”也保留已有录音及评分。
- **原声采集：** 受浏览器和视频音轨限制，部分视频可能无法获取原声音高；不影响字幕阅读和逐句停顿。

## 开发与自检

```sh
npm run dev       # 开发监听
npm run doctor    # 检查/修复已知缺失，构建并验证扩展
npm run verify    # 构建与扩展端到端测试
```

自动验收使用独立测试浏览器、模拟字幕、媒体及有道响应，不使用真实账户或产生有道用量；截图位于 `artifacts/verification_latest.png`，不是用户日常浏览器或真实付费接口验收。
